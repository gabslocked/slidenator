# Slidenator

## What it is

SaaS that generates **interactive HTML presentations** (16:9 stage, live simulations, animated charts, clickable demos) from a conversation. An onboarding assistant interviews the user in a chat, collects logo/colors/documents via drag-and-drop, a pipeline of agents (roteirista → diretor visual → engenheiro de interação → construtores → revisor) builds the slides, and the user keeps editing the presentation by talking in the same chat. The presentation stays "alive" in the conversation (floating pill, versioned v1 → v2 …).

## Audience

Brazilian professionals (pt-BR product language): devs, managers, consultants, teachers — anyone who needs a persuasive presentation without design skills. Multi-tenant: Individual, Teams, Enterprise orgs.

## Register

- `app/` (chat UI, login) → **product** — design serves the tool; calm, invisible, fast.
- `landing/` (slidenator.com.br / www.slidenator.com) → **brand** — editorial sólido language (ImobSight-derived), sober desaturated blue-graphite accent, three.js blueprint hero, the real product interface as protagonist.

## Platform

web

## Voice

Calorosa e direta, pt-BR, zero jargão. NEVER mentions which AI models/vendors power it ("o motor do Slidenator"). No invented metrics, no fake testimonials, no "X dias grátis".

## Brand personality

Contido, preciso, vivo. The product's flash lives in the *generated presentations* (which carry each org's own brand kit), not in the tool chrome. The tool itself is quiet: white, neutral grays, black actions.

## Anti-references

- Loud SaaS gradients, purple-on-dark AI clichés, glassmorphism cards.
- Any copy that says "deck" (product vocabulary is "apresentação"/"slides").
- Vendor/model name-dropping in UI.
